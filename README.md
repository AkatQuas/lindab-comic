# 这漫画有点傻 · 备份合集

《这漫画有点傻》漫画图片的本地备份存档，共 79 篇（编号 0–78），附带一个单图浏览页面。

## 浏览

打开 [index.html](https://akatquas.github.io/lindab-comic/) 即可浏览，无需任何服务端：

- 一次只展示一张图
- 「上一张 / 下一张」按钮或键盘 `←` / `→` 切换
- 顶部下拉列表可按名称直接跳转

## 目录结构

```
├── index.html      # 单图浏览页面
├── manifest.js     # 漫画清单（编号 + 名称）
├── manhua.js       # 早期的抓取脚本（原服务已停止，仅作历史存档）
└── *.jpg           # 漫画图片，命名规则：<编号><名称>.jpg
```
